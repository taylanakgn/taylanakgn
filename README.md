### Building

**ShadowBridge** — Mule account networks operate *between* banks. Each institution only
sees its own fragment of the pattern, and data protection rules prevent them from
comparing notes directly. ShadowBridge is a federated learning architecture where banks
train a shared detection model without raw customer data ever leaving their perimeter.

- **Why it matters:** directly relevant to AML/MASAK reporting obligations
- **Hard part:** the approach needs two cooperating institutions to be real — I work
  around it with a synthetic two-bank federated demo
- **Status:** architecture done, demo running
